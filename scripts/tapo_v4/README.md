# Reference only — not used at runtime

Netductor uses a **pure Go** TPAP/SPAKE2+ port in `internal/tapo` (no Python).

This tree is a vendored copy of [freeKC/tapo-v4-protocol](https://github.com/freeKC/tapo-v4-protocol) (MIT) kept as a **protocol reference** and offline cross-check. Do not install as a dependency of the agent or primary binary.
