# Client profiles

## SR Config (Mac + OpenConnect)

Repo: `configs/profiles/nd-oc.conf`  
Deploy path: `/opt/netductor/profiles/nd-oc.conf`

**Delivery:** TG → Users → Access → **SR Config** (document).

Contents:

1. Corporate / LAN `skip-proxy` + tealpos DIRECT  
2. **RU/gov/banks DIRECT** (Gosuslugi stack, marketplaces, GEOIP RU)  
3. `FINAL,PROXY` → your VLESS from bot  

Usage: OpenConnect first → import config → Global Routing = Config.

## Sing-box client JSON

Generated by `netductor vpn client-config <user>`:

- RU suffixes/keywords + `geoip-ru` → `direct`
- DNS for RU → Yandex `77.88.8.8`
- Final → secondary relay or core-via-relay

See `docs/ru/SHADOWROCKET.md`.
