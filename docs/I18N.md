# i18n (EN + RU)

## Rule

### UI
Every user-visible string in TG / TUI / Web / operator-facing CLI → both languages in the **same change**.

### Documentation (`docs/` ↔ `docs/ru/`)
**Mandatory full semantic parity** (owner standing rule):

| Allowed | Forbidden |
|---------|-----------|
| Same meaning, natural RU/EN wording | RU as a short digest of EN |
| Same structure / same decisions & numbers | “We’ll translate later” |
| Parallel files for every product doc | Condensed RU for long design docs |

Agents and humans: a PR/commit that changes EN docs without the RU pair (or the reverse) is **not done**.

## Surfaces
| Surface | Mechanism |
|---------|-----------|
| TG | `T("key")` in `cmd/netductor-tg/i18n.go` |
| TUI | `FormT` / `TT` in `tui_l10n.go` |
| Web | `data-i18n` + `I` map in `app.js` |
| CLI doctor | `cli18n.T` |
| opcatalog | `LabelEN` / `LabelRU` |
