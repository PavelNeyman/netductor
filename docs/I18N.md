# i18n (EN + RU)

## Rule
Every user-visible string in TG / TUI / Web → both languages in the same change.

## Surfaces
| Surface | Mechanism |
|---------|-----------|
| TG | `T("key")` in `cmd/netductor-tg/i18n.go` |
| TUI | `FormT` / `TT` in `tui_l10n.go` |
| Web | `data-i18n` + `I` map in `app.js` |
| CLI doctor | `cli18n.T` |
| opcatalog | `LabelEN` / `LabelRU` |
