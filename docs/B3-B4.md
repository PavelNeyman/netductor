# B3 / B4 posture

## B3 Desired state via agent plane
- Secondary config: heartbeat `need_sync` → pull `/api/secondary/agent/config` (mTLS :8789)
- Failover policy: `failover_policy` on heartbeat
- Hostname: `desired_hostname`
- **Do not** SSH primary→secondary for day-2 config after bootstrap

## B4 Operator secrets on Mac
- `~/.ssh/netductor_primary` private key stays on Mac
- Primary holds **operator pubkey** only (authorized_keys)
- Recover injects pubkey via env/backup, not private key upload to VPS
