- Release lag vs `main` — TG warns; prefer release for prod.

- Admin UI only over VPN by policy (not exposed).

## Update policy (agreed)

1. **Primary**: operator-triggered from GitHub **Release** assets (not raw main).
2. **Secondary**: command/upgrade via control plane.
3. **Agents**: **no** auto mesh update; `agent_update` per device when operator chooses.
4. New primary version **may bundle** agent binary in release assets; UI notifies, does not force.
