# SNI presets

Список handshake SNI для Reality (белые списки операторов).

Файл: `/etc/netductor/sni_presets.json`  
API: `GET /api/sni-presets`  
Admin → вкладка SNI.

Сейчас **не переключает** live-конфиг автоматически — только справочник. Когда появятся БС на Yota, выбираем preset и пересобираем relay/core Reality SNI.
