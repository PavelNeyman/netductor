## Как воспроизвести статический прогон

В чистом sandbox Go нет; здесь использован `apt install golang-go` (1.22.2). Модули на vanity-доменах заменялись зеркалами GitHub **только во временной копии** (`go mod edit -replace golang.org/x/<m>=github.com/golang/<m>@<ver>`, аналогично `gopkg.in/yaml.v3` → `github.com/go-yaml/yaml/v3`, `gopkg.in/check.v1` → `github.com/go-check/check`). `deadcode` собран из `github.com/golang/tools` версии `v0.28.0`. Запускать `deadcode ./...` для каждого поставляемого `GOOS`.
