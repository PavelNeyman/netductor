## 8. Структура и логика меню Telegram (новое)

Пройти каждый хаб TG и вложенные экраны. Сделать навигацию структурированной и логичной.

Правила:
- Разные кнопки не должны вести в одно и то же место без явной причины.
- Нет дублей действий под двумя хабами (клон Status под Tools и т.п.).
- Префиксы callback однозначны (`m:sshkeys:` vs hosts, `m:git:proj:*` vs другие).
- Набор хабов: Status / Users / Fleet / Tools / Operator.
- Tools = только day-2 (без клонов Status/Users/Fleet).
- Тело карточки короткое; действия — кнопки.
- После изменений обновить карту callback в [PLAN-TG-MENU.md](PLAN-TG-MENU.md), если префиксы сдвинутся.
