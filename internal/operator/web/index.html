Modules

Only capabilities detected on the device are enabled by default. Advanced unlocks skipped modules at your risk.

Module parameters

Prefills from current device settings when known. Only modules you enabled are applied (merge, not full reset).

LAN

Shops: prefer 10.120.<N>.0/24 (see Network map in Settings). Avoid 10.9.8 home and 10.88 service-net.

WAN / uplink

Uplink to ISP. DNS optional (e.g. 1.1.1.1 9.9.9.9). Not the same as VPN DNS mode on the client.

Optional

Wi‑Fi AP

Fill 2.4 GHz only if you want — empty 5 GHz SSID/key is copied from 2.4 (and the other way around). Both bands applied when radios exist.

Guest

Isolated SSID; clients use ISP (not router VLESS). PSK = Wi‑Fi password; desk PIN = staff grant.

Edge storage (USB)

Day-2: backup A+B, mute USB alerts, restore from primary or offline pack path on device.
